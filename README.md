# TrafficLab

**Advanced research framework for generating, modeling, analyzing and exporting synthetic network traffic**

## Features

- **70+ Protocols**: Ethernet II, IEEE 802.3, LLC, SNAP, ARP, RARP, VLAN, QinQ, LLDP, CDP, IPv4, IPv6, ICMP, ICMPv6, IGMP, TCP, UDP, SCTP, DCCP, GRE, MPLS, VXLAN, Geneve, DNS, DHCP, BOOTP, HTTP/1.0, HTTP/1.1, HTTP/2, HTTP/3, HTTPS, TLS 1.2, TLS 1.3, DTLS, FTP, TFTP, SMTP, POP3, IMAP, SNMP, NTP, LDAP, Kerberos, SIP, RTP, RTCP, RTSP, MQTT, AMQP, CoAP, SSDP, mDNS, LLMNR, NetBIOS, Syslog, RADIUS, TACACS+, Redis RESP, Memcached, WebSocket

- **11 Network Profiles**: Office, Enterprise, Home, University, IoT, Cloud, Data Center, ISP, Industrial, Telecom

- **Realistic Session Generation**: Protocol conversations, not isolated packets

- **Multiple Export Formats**: PCAP, PCAPNG, JSON, YAML, CSV, Markdown

- **Advanced Analysis**: Protocol statistics, flow analysis, histograms, timeline, top talkers

- **Visualization**: Pie charts, histograms, flow graphs, network graphs

- **Enterprise Architecture**: SOLID, DRY, KISS, Dependency Injection, Type Hints, Pydantic V2, AsyncIO
